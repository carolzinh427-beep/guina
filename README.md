# Guina Restaurante & Wine Bar

Site institucional e gastronômico para o **Guina Restaurante & Wine Bar**, inspirado na alta gastronomia clássica e contemporânea e no universo dos vinhos finos.

---

## ⚜️ Identidade Visual & Conceito
- **Paleta de Cores:** Azul Marinho Real Nobre (`#0A172A`, `#050B14`, `#0D1F38`) com detalhes em Ouro Envelhecido / Dourado Metálico (`#D4AF37`, `#F5E7B2`) e toques florais de Hortênsias Azuis.
- **Logotipo:** Placa nobre barroca com detalhes em relevo dourado, flor-de-lis, luminárias decorativas, cachos de uvas com parreirais e arranjo de hortênsias.
- **Tipografia:** *Playfair Display* & *Cinzel* para títulos nobres de época e *Inter* para leitura moderna e fluida.

---

## 🍽️ Principais Seções e Funcionalidades
1. **Navegação Inteligente (Navbar):** Menu responsivo com efeito de rolagem dinâmica (pill flutuante de vidro escuro e ouro) e drawer para dispositivos móveis.
2. **Hero Section:** Apresentação visual imersiva com a placa e insígnia oficial do Guina Restaurante, selo de avaliação Google (4.9 estrelas) e botões rápidos de ação.
3. **Destaques & Premiações:** Barras com selos de restaurante premiado, pontuação máxima, chefs Le Cordon Bleu e melhor experiência gastronômica.
4. **Nossa História (About):** Narrativa sobre a trajetória do restaurante, atmosfera romântica e compromisso com ingredientes nobres.
5. **Avaliações Verificadas (Reviews):** Carrossel interativo com depoimentos reais de clientes, pontuação 4.9/5.0 e link direto para o Google Reviews.
6. **Cardápio Digital Completo:**
   - 59 pratos catalogados com fotos de alta qualidade, descrições detalhadas e preços.
   - Filtro instantâneo por categorias (Entradas, Carnes, Peixes e Frutos do Mar, Sobremesas, Brunch, Cocktails, etc.).
   - Campo de busca em tempo real.
   - Adição direta ao carrinho de pedidos.
7. **Wine Bar & La Cave:** Seção dedicada à carta de vinhos com mais de 120 rótulos selecionados e serviço de sommelier.
8. **Galeria de Ambientes:** Fotografias do restaurante, iluminação intimista à luz de velas e mesas externas, com visualizador em tela cheia (Lightbox).
9. **Sistema de Reservas Online:**
   - Calendário interativo para escolha de dia e mês.
   - Seleção de horários disponíveis conforme os dias de funcionamento (Terça a Domingo).
   - Contador de convidados e seleção do ambiente (Salão Nobre Interno ou Área Externa & Flores).
   - Geração automática de código de reserva e envio estruturado para o WhatsApp oficial.
10. **Carrinho & Checkout WhatsApp:** Finalização rápida de pedidos com cálculo de total e envio formatado.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js (v18 ou superior)
- npm

### Instalação
```bash
npm install
```

### Modo de Desenvolvimento
```bash
npm run dev
```

### Compilação para Produção
```bash
npm run build
```

O diretório `dist/` conterá os arquivos estáticos otimizados prontos para deploy na Vercel, Netlify, GitHub Pages ou qualquer servidor web.
